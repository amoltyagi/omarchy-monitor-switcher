# Screenshots

These are real Monitor Switcher 3 panel captures, cropped to the plugin surface.
Rounded-corner masking removes the surrounding desktop; the controls and display
values are unaltered. Captured September 16, 2026.

- `displays.png` — main panel, with MSI, LG and Acer connected.
- `arrangement.png` — the arrangement view of the same setup.

The editable launch artwork is in `../hero.svg` and `../arrangement.svg`. Render
from the repository root with:

```bash
rsvg-convert assets/hero.svg -o preview.png
rsvg-convert assets/arrangement.svg -o preview-detail.png
```
